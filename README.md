# Woolly Workplace Relay

Shared vault folders for the Woolly Workplace — an Obsidian plugin.
Fork of [Relay](https://github.com/No-Instructions/Relay) (MIT, © 2024
No Instructions, LLC) pointed at the workplace's self-hosted server.

## Install

1. In Obsidian, install the community plugin **BRAT** and enable it.
2. BRAT settings → *Add beta plugin* → `PicoBEAN-eng/woolly-relay` → Add.
3. Enable **Woolly Workplace Relay** in Community plugins.
4. In the plugin settings, **Sign in with Google** (your workplace-listed
   account). Your folders appear at the vault root automatically.

No share keys, no server settings — if your email is on the allowlist,
sign-in is all there is.
